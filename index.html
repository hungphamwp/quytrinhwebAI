Kho tài liệu: Quy trình làm Web bằng AI

Đây là nơi lưu trữ và tích lũy kiến thức, công cụ, quy trình liên quan đến việc làm website/ứng dụng bằng AI. Mỗi khi có nghiên cứu mới — một công cụ mới, một quy trình mới, một kinh nghiệm mới — tài liệu tương ứng sẽ được thêm vào đây.

Tài liệu hiện có

Base44

Quy trình làm web mẫu bằng AI

Hướng dẫn dành cho khách hàng không rành kỹ thuật, dùng app.base44.com để tạo website mẫu.
OpenRouter + Orca

Tích hợp OpenRouter vào Orca (model miễn phí)

Cấu hình Claude Code trong Orca dùng model miễn phí của OpenRouter — ví dụ minimax/minimax-m3:free.
Canva MCP

Dùng Canva MCP thiết kế banner bằng AI

Quy trình tạo, chỉnh sửa và xuất banner quảng cáo ngay trong Claude Code, kể cả chèn logo riêng vào template có sẵn.
Chiến dịch FB

Chiến dịch Facebook → Khách làm website WordPress

Bộ tài liệu gồm sơ đồ dòng chảy, kế hoạch 10 phần, bảng web AI, 7 bài đăng nhóm và hệ thống Content & Design 2 tầng.

Danh sách sẽ tiếp tục được bổ sung theo thời gian.

Cấu trúc kho tài liệu

.
├── index.html              # Trang chủ (file này)
├── assets/style.css        # Giao diện dùng chung
└── docs/
    ├── base44-quy-trinh-lam-web.html   # Quy trình làm web mẫu (Base44)
    ├── openrouter-vao-orca.html        # Tích hợp OpenRouter vào Orca
    ├── canva-mcp-thiet-ke-banner.html  # Dùng Canva MCP thiết kế banner
    ├── chien-dich-facebook-web-ai/     # Chiến dịch Facebook → web WordPress
    └── ...                 # các tài liệu mới sẽ thêm vào đây

Quy ước khi thêm tài liệu mới

  • Mỗi tài liệu mới là một file HTML trong thư mục docs/, dùng chung assets/style.css.
  • Đặt tên file theo dạng ten-cong-cu-hoac-chu-de.html (không dấu, cách nhau bằng gạch ngang).
  • Sau khi thêm tài liệu mới, cập nhật thêm mục trong sidebar và bảng ở trang chủ này.
Kho tài liệu được cập nhật liên tục. Mọi thắc mắc xin liên hệ trực tiếp đội dự án.
