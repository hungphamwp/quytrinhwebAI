## 🖥️ Cách xem

Mở bằng trình duyệt (mở file trực tiếp hoặc chạy server tĩnh):

```bash
# từ thư mục repo
python3 -m http.server 8899 --bind 127.0.0.1
# rồi mở: http://127.0.0.1:8899/docs/chien-dich-facebook-web-ai/facebook-campaign-tabs.html
```

> ⚠️ Các file HTML đặt cùng thư mục `thumbnails/` nên ảnh tự hiển thị. Giữ nguyên cấu trúc.
> `facebook-campaign-tabs.html` nhúng toàn bộ phần sơ đồ & bảng web AI.

## 🔁 Chiến lược 2 tầng (tóm tắt)

- **Tầng Free (ai cũng làm được):** dùng công cụ AI miễn phí, **chỉ cách làm** → gieo hạt, kéo tương tác.
- **Tầng Pro (chỉ mình làm được):** sản phẩm xịn bằng công cụ trả phí/kỹ thuật cao, **chỉ show off, không chỉ cách** → định vị chuyên gia.
- **Nhịp đăng xen kẽ:** ngày khoe "xịn" (tầng Pro) ↔ ngày dạy "cách làm free" (tầng Free).
- **Quy trình nội bộ** (không đăng): nhận link demo → clone trang → chuyển WordPress → dựng bằng skill HTML→ACF → bàn giao.
