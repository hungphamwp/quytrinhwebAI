6️⃣ Đánh giá demo — checklist

  • Tên miền: là *.subdomain của nền tảng? → bán domain riêng
  • Quảng cáo/badge: có logo/quảng cáo? → bán bản "sạch"
  • Nội dung: giữ được bố cục, hình, menu, giá? → điểm cần giữ
  • Chỉnh sửa: đổi được chữ/hình không? → bán "tự quản trị"
  • SEO: có tiêu đề, mô tả, URL thân thiện? → bán SEO
  • Tốc độ/mobile: nhanh, hiển thị điện thoại ổn? → bán tối ưu
  • Số trang/tính năng: cần form liên hệ, bản đồ, đặt lịch, thanh toán?
  • Ý đồ khách: web để làm gì? → báo giá đúng nhu cầu

8️⃣ Chuyển sang WordPress — quy trình kỹ thuật

Chuẩn bị hạ tầng

  • Mua tên miền riêng (giữ quyền cho khách) · Hosting WordPress · Cài WordPress + SSL.

Dựng site từ link demo

  • Bật plugin: Rank Math/SEO, WP Rocket, Wordfence, UpdraftPlus, Elementor.
  • Tạo theme + design. Dựng lại nội dung theo demo (chữ, hình, menu, trang).
  • Nâng chất: responsive, form liên hệ, bản đồ. Cấu hình SEO + Search Console + tốc độ.
  • Kiểm tra: PageSpeed, mobile, nút, form, không lỗi 404.

Checklist bàn giao

  • Domain riêng + SSL hoạt động
  • Không còn badge/quảng cáo của nền tảng AI
  • Đầy đủ trang + nội dung khách cần
  • Form liên hệ gửi về email/SĐT khách
  • Chạy nhanh trên điện thoại
  • Khách tự đăng nhập thay đổi được nội dung (điểm bán quan trọng!)
  • File backup + tài khoản quản trị bàn giao cho khách

9️⃣ Bàn giao & bảo trì

  • Bàn giao: hướng dẫn đăng nhập /wp-admin, đổi mật khẩu, cách đổi nội dung (quay video 5 phút).
  • Nghiệm thu: khách xác nhận, nhận phần còn lại.
  • Bảo hành: 1-3 tháng sửa lỗi miễn phí.
  • Bảo trì: sao lưu, update theme/plugin, kiểm tra tốc độ & SEO — thu phí tháng.
  • Upsell: chạy quảng cáo cho web, SEO, viết nội dung, thêm tính năng.
✅ Việc cần làm: chuẩn bị video hướng dẫn quản trị 5 phút — giúp khách tin bạn & giảm hỗ trợ về sau.

DQuy trình nội bộ — ChatGPT → Prompt → Web AI

Quy trình tạo website cho khách: lấy brief → ChatGPT viết prompt → chọn tool → dán prompt → AI tạo web → chỉnh sửa → bàn giao. Đây là quy trình nội bộ, không đăng cho khách xem.

🔒 Nội bộ: phương pháp này là công thức riêng của bạn, không chia sẻ cho khách/đối thủ. Dùng để tạo nhanh & hiệu quả.

📊 Sơ đồ quy trình (6 bước, 85-120 phút)

🔁 Tổng quan quy trình (6 bước)

BướcViệc cần làmCông cụ / ToolThời gian
1. Lấy briefKhách gửi nhu cầu: ngành, ý tưởng, target, tính năng cần (form, giá, v.v)Messenger / Form / Zalo~15 phút
2. Viết promptDùng ChatGPT tạo prompt chi tiết để AI tạo website dựa trên briefChatGPT / Claude~20 phút
3. Chọn tool AIDựa trên ngành & nhu cầu, chọn tool web AI phù hợp (Durable/Wix/Framer/...)Bảng cột 1~5 phút
4. Tạo webDán prompt vào tool → AI tạo website tự động (chỉ cần 2-3 phút)Tool web AI~5 phút
5. Chỉnh sửaReview & tinh chỉnh: nội dung, ảnh, bố cục, form, SEOTool web AI~30-60 phút
6. Bàn giaoTest, copy link, gửi khách + hướng dẫn sửa nội dungMessenger / Zalo~10 phút

⏱️ Tổng cộng: 85-120 phút (~1.5-2 tiếng) từ brief → website sẵn dùng

⚙️ Chi tiết từng bước (checklist triển khai)

Bước 1 — Lấy brief từ khách

  • Ngành/lĩnh vực: gì (dịch vụ, bán hàng, portfolio)?
  • Mục đích: giới thiệu? bán? chạy quảng cáo?
  • Tính năng cần: form liên hệ? giá? bản đồ? đặt lịch? giỏ hàng?
  • Style mong muốn: màu, tone, reference (nếu có).

Bước 2 — Viết prompt bằng ChatGPT

  • Mở ChatGPT → dùng template prompt ở dưới.
  • Thay các [...] bằng thông tin khách (ngành, nhu cầu, tính năng).
  • Chat với Claude/ChatGPT để prompt chi tiết, cụ thể, dễ hiểu.
  • Copy prompt hoàn chỉnh để dùng ở bước tiếp.

Bước 3 — Chọn tool web AI phù hợp

  • Ngành bán hàng/dịch vụ địa phương → Durable (nhanh)
  • Landing page hiện đại → Lindo / Framer (đẹp)
  • Cần flexibility → Wix / Webflow (tuỳ chỉnh nhiều)
  • Portfolio/thương hiệu → Framer (animation)
  • Dữ liệu động → Softr (nối Google Sheets)

Bước 4 — Tạo web bằng tool (chỉ 5 phút!)

  • Vào tool web AI đã chọn → chọn "Tạo bằng AI" hoặc "Generate".
  • Dán prompt vừa viết vào ô prompt/description.
  • Bấm "Generate" hoặc "Create" → chờ AI tạo (~2-3 phút).
  • Tool tự động tạo layout, nội dung, ảnh, màu sắc.

Bước 5 — Chỉnh sửa & hoàn thiện

  • Review toàn bộ website: nội dung, ảnh, bố cục, form.
  • Chỉnh: đổi ảnh, sửa text, thay màu, điều chỉnh section.
  • Kiểm tra mobile view, thử form, test link.
  • Lưu tất cả thay đổi.

Bước 6 — Bàn giao cho khách

  • Copy link website → gửi khách (Messenger / Zalo).
  • Ghi chú: "Web của bạn đã tạo xong, bạn có thể sửa nội dung trực tiếp".
  • Nếu khách muốn domain riêng/WordPress → báo giá & hướng dẫn bước tiếp.
