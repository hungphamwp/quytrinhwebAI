DQuy trình nội bộ — Chuyển web AI → WordPress

Quy trình KHI CÓ KHÁCH: nhận link demo → clone trang → chuyển WordPress → dùng skill HTML→ACF → bàn giao. Đây là quy trình nội bộ, không đăng cho khách xem.

🔒 Nội bộ: tab này dành cho bạn triển khai, không chia sẻ cho khách/đối thủ. Chỉ dùng khi làm việc thật với khách.

⚙️ Chi tiết từng bước (checklist triển khai)

Bước 1 — Nhận & đánh giá

  • Nhận link demo từ khách (Messenger / Form / Zalo).
  • Mở web, chụp/ghi lại toàn bộ: trang chủ, các trang con, menu, banner, footer.
  • Ghi nhận nhu cầu: bán hàng? giới thiệu? chạy quảng cáo? cần form/đặt lịch?
  • Chốt phạm vi + bảng giá + tiến độ với khách.

Bước 2 — Clone trang

  • Clone/lưu toàn bộ trang khách gửi làm bản gốc tham chiếu (thiết kế, hình, cấu trúc).
  • Lưu lại hình ảnh, font, màu, bố cục từng section.
  • Tạo bản mô tả (wireframe/spec) để giữ đúng ý tưởng khi lên WordPress.

Bước 3 — Chuyển sang WordPress

  • Dựng môi trường: hosting + cài WordPress + SSL + tên miền.
  • Chọn theme/builder phù hợp (Elementor / Kadence / GeneratePress / theme tuỳ chỉnh).
  • Tạo cấu trúc trang giống bản clone: Home, Giới thiệu, Sản phẩm/Dịch vụ, Liên hệ...
  • Đưa nội dung + hình ảnh lên, giữ đúng bố cục.

Bước 4 — Triển khai bằng skill HTML → ACF

  • Dùng skill HTML → ACF (Advanced Custom Fields) để dựng block/khối nội dung động.
  • Sử dụng ACF để khách tự nhập nội dung mà không phải sửa code: tiêu đề, ảnh, giá, mô tả, bài viết.
  • Map từng phần của bản clone vào các field/block ACF cho chuẩn & linh hoạt.
  • Kiểm tra responsive (mobile/tablet/desktop), chỉnh layout chi tiết.

Bước 5 — Bàn giao

  • Chạy kiểm tra: tốc độ (PageSpeed), SEO (tiêu đề/mô tả/sitemap), form liên hệ, mobile, không lỗi 404.
  • Bàn giao tài khoản quản trị + video hướng dẫn tự sửa nội dung (nhờ ACF nên dễ).
  • Bảo hành 1-3 tháng + chốt gói bảo trì.
