4Đưa khách tự tạo demo — từng bước

Đây là hướng dẫn bạn gửi khách (tự động hoặc 1 bài cẩm nang), để họ tạo demo & gửi link trong <10 phút.

Hướng dẫn dùng Hostinger Horizons (chuẩn)

  • Vào hostinger.com → bấm AI Website Builder (Horizons).
  • Bấm Try for Free / Start for free.
  • Mô tả ngành + ý tưởng vào ô prompt (VD: "web giới thiệu quán cà phê, có menu và giá").
  • Chọn layout/ảnh AI đề xuất → bấm Generate.
  • Điền thông tin cửa hàng (tên, SĐT, địa chỉ, giờ mở cửa).
  • Copy địa chỉ website bản free → gửi link đó cho mình.

Hướng dẫn dùng Wix (kéo-thả)

  • Vào wix.com → Create a website with AI.
  • Đăng ký (Google/Facebook/email).
  • Mô tả website, chọn phân loại → Generate.
  • Sửa nhanh bằng kéo-thả nếu muốn.
  • Copy link *.wixsite.com/... → gửi lại.

Hướng dẫn dùng Framer

  • Vào framer.com → Generate a website.
  • Đăng ký, mô tả ý tưởng → chọn template → Framer tự dựng.
  • Copy link *.framer.website → gửi lại.

6Đánh giá demo — checklist

Mở link lên, chấm theo checklist rồi ghi 3-5 ý chính vào cột Ghi chú. Đây là "bia" để bạn tư vấn.

📋 Checklist đánh giá website demo

  • Tên miền: là *.subdomain của nền tảng? → bán domain riêng
  • Quảng cáo / badge: có logo/quảng cáo của Wix/Framer? → bán bản "sạch"
  • Nội dung: giữ được bố cục, hình ảnh, menu, giá, video? → điểm cần giữ
  • Chỉnh sửa: khách đổi được chữ/hình không, hay bị khoá? → bán "tự quản trị"
  • SEO: có tiêu đề, mô tả, URL thân thiện? → bán SEO bài bản
  • Tốc độ / mobile: chạy nhanh, hiển thị điện thoại ổn? → bán tối ưu
  • Số trang / tính năng: cần form liên hệ, bản đồ, đặt lịch, thanh toán?
  • Ý đồ khách: web để làm gì (bán hàng / giới thiệu / chạy quảng cáo)? → báo giá đúng
🎤 Câu tư vấn mở đầu chuẩn: "Mình đã xem web của bạn. Nền tảng AI free làm được điểm mạnh này [khen cụ thể]. Nhưng nó đang vướng vấn đề này [điểm đau]. Để web chuẩn, chạy nhanh, lên Google được và bạn tự sửa nội dung — mình làm lại trên WordPress, giữ nguyên ý tưởng + nội dung. Mình báo giá 2 gói ở dưới nhé."

  • Thời gian bàn giao, số lần chỉnh sửa, chế độ bảo hành.
  • Điều khoản thanh toán (đặt cọc 30-50%, còn lại khi nghiệm thu).
  • Quyền sở hữu sau khi hoàn tất.

8Chuyển sang WordPress — quy trình kỹ thuật

Mỗi link demo → 1 website WordPress hoàn chỉnh.

8.1 Chuẩn bị hạ tầng (1 lần / 1 dự án)

  • Mua tên miền riêng (.com, .vn...) — giữ quyền sở hữu cho khách.
  • Mua hosting WordPress (Hostinger/Namecheap/Cloudways) hoặc VPS.
  • Cài WordPress (1-click) + SSL (Let's Encrypt miễn phí).

8.2 Dựng site từ link demo (thứ tự)

  • Bật plugin: Rank Math/SEO, WP Rocket (cache), Wordfence (bảo mật), UpdraftPlus (backup), Elementor.
  • Tạo theme (Elementor/Kadence/GeneratePress) + design phù hợp.
  • Dựng lại nội dung theo demo: chuyển chữ, hình, menu, trang cần.
  • Nâng chất: đẹp hơn, chuẩn mobile, form liên hệ, bản đồ.
  • Cấu hình SEO: tiêu đề, mô tả, URL thân thiện, sitemap, Search Console, tốc độ.
  • Kiểm tra: tốc độ (PageSpeed), mobile, nút, form, không lỗi 404.

8.3 Checklist bàn giao nội bộ

  • Domain riêng + SSL hoạt động
  • Không còn badge/quảng cáo của nền tảng AI
  • Đầy đủ trang + nội dung khách cần
  • Form liên hệ gửi được về email/SĐT khách
  • Chạy nhanh trên điện thoại
  • Khách tự đăng nhập thay đổi được nội dung (điểm bán quan trọng!)
  • File backup + tài khoản quản trị bàn giao cho khách

9Bàn giao & bảo trì

  • Bàn giao: hướng dẫn khách đăng nhập /wp-admin, đổi mật khẩu, cách đổi nội dung (quay video 5 phút gửi khách).
  • Nghiệm thu: khách xác nhận, nhận phần còn lại.
  • Bảo hành: 1-3 tháng sửa lỗi miễn phí (tuỳ chính sách bạn).
  • Bảo trì định kỳ: sao lưu, update theme/plugin, kiểm tra tốc độ & SEO — thu phí tháng.
  • Upsell: chạy quảng cáo Facebook/Google cho web, SEO, viết nội dung, thêm tính năng.
✅ Việc cần làm: chuẩn bị video hướng dẫn quản trị 5 phút (quay màn hình đổi nội dung). Video này giúp khách tin bạn & giảm gọi hỗ trợ về sau.
